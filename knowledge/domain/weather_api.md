# Weather data contract

Open-Meteo current weather codes are mapped to clear, cloud, rain, and snow on the phone. The clock and courier do not require weather data.

Phone refreshes require location and network access. The watch displays unavailable when a fetch fails or the received state is more than one hour old.

Source: [Open-Meteo forecast documentation](https://open-meteo.com/en/docs).
